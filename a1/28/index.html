MERKECheat sheet: the grammar of this sheet
The exam: Sprechen
About 15 minutes, in a small group. Teil 1: introduce yourself. Teil 2: ask and answer questions with a card (one word). Teil 3: make a request and react to a request.
Teil 1: me
nameIch heiße Maria Santos. (S-A-N-T-O-S)
countryIch komme aus den Philippinen.
townIch wohne in München.
ageIch bin 29 Jahre alt.
languagesIch spreche Tagalog, Englisch und Deutsch.
job · hobbyIch arbeite in einer Firma. Mein Hobby ist Fußball.
Teil 2: ask
Hobby → Was ist dein Hobby? · Wohnort → Wo wohnen Sie? · Geburtstag → Wann hast du Geburtstag? Question word first, verb in position 2. The answer is a sentence.
Teil 3: request
Kannst du …? / Können Sie …? → Natürlich! · Ja, gern. · Tut mir leid, das geht nicht. Also possible: Machen Sie bitte das Fenster auf.
